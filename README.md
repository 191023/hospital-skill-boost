# Hospital Skill Hub

ผมอยากสร้าง website สำหรับฝึกอบรม online บุคลากรของโรงพยาบาล  ที่สามารถเรียนรู้บทเรียน และประเมินผลการทดสอบ ก่อนและหลังการเรียนรู้ได้  สามารถออกใบประกาศหรือ certificate  ให้กับผู้ผ่านการอบรมได้ พร้อมทั้งระบบสรุปผลการฝึกอบรมทั้งหมด   และระบบตั้งค่าต่าง เช่นระบบสมาชิก ระบบการสร้างหลักสูตรฝึกอบรม และระบบอื่นๆ
