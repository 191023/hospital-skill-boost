# SEO & Web Accessibility (WCAG 2.1) Standards

Follow these guidelines for every HTML document and page layout:

## 1. Semantic HTML Structure
- Use semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
- Include exactly one `<h1>` heading per page, followed by logical `<h2>` to `<h6>` hierarchy.

## 2. Accessibility (WCAG 2.1 AA)
- Provide descriptive `alt` text for images and visual elements.
- Add `aria-label` or `aria-labelledby` for interactive buttons and icon controls.
- Ensure color contrast ratios meet WCAG AA standards (minimum 4.5:1 for normal text).
- Ensure all interactive elements are reachable and operable via keyboard navigation.

## 3. SEO Metadata
- Provide descriptive `<title>` tags and `<meta name="description">` content.
- Include standard OpenGraph meta tags (`og:title`, `og:description`, `og:image`) for social media previews.
